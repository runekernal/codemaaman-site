# 💻 CodeMaaman

CodeMaaman is a single-page landing website for a coding community/club, built 
to welcome visitors with a modern, animated interface and give them a quick 
overview of who the community is, what they teach, and how to get in touch.

## Features

- 🌗 **Dark / Light Mode Toggle** — Instantly switch themes, complete with theme-aware 
  logo, illustrations, and Lottie animations
- ⌨️ **Typewriter Hero** — Animated rotating tagline ("Learn. Code. Grow. Innovate. Succeed.")
- 📑 **Tabbed About Section** — Switch between CodeMaaman, Mission, and Vision, each with 
  its own animated Lottie icon
- 🎓 **Event Bootcamp Cards** — Showcases programs like UI/UX, Web Development, Python, 
  and AI bootcamps with tags and quick "Join now" actions
- 📬 **Contact Section** — A contact form alongside embedded Google Maps and direct 
  email/phone links
- 🧭 **Scroll-Aware Navigation** — Nav bar highlights the active section and updates 
  the URL hash as you scroll

## Tech Stack

- HTML5 / CSS3
- Vanilla JavaScript (ES6+)
- [Lottie](https://airbnb.design/lottie/) for vector animations
- [Remix Icon](https://remixicon.com/) & [Font Awesome](https://fontawesome.com/) for iconography
- Google Maps embed for location
